# Software FJ - Gestión de Reservas
Tarea 4 - Sistema integral orientado a objetos desarrollado en Python para la gestión de clientes, servicios y reservas de la empresa Software FJ.

## Descripción del proyecto

El sistema permite administrar:

- Registro de clientes
- Reserva de salas
- Alquiler de equipos
- Asesorías especializadas
- Gestión de reservas
- Validaciones y manejo de excepciones
- Registro de errores mediante archivos log

El proyecto fue desarrollado aplicando principios de Programación Orientada a Objetos (POO):

- Abstracción
- Herencia
- Polimorfismo
- Encapsulación
- Manejo avanzado de excepciones

## Estructura del proyecto

- `cliente.py` → Gestión y validación de clientes.
- `Servicio_baseabstracta.py` → Clase abstracta de servicios.
- `servicios.py` → Servicios especializados.
- `reserva.py` → Gestión de reservas.
- `main.py` → Ejecución y pruebas del sistema.
